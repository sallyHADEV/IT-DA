# 잇다 (IT-DA)

플로우차트 기반 **상황 인식형** 매크로 도구. Windows 데스크톱 전용.

UiPath를 참조하되 무거운 기능은 걷어내고, 한 가지 개념만 중심에 뒀다 —
**"타겟 프로그램의 상황(화면)을 먼저 인식하고, 동작에 필요한 화면이 아니면
스스로 그 화면으로 이동한 뒤 동작한다."** 좌표를 무작정 클릭하는 매크로가 아니라
지금 화면이 무엇인지 스스로 판정하고 움직인다.

## 📖 [사용 설명서 보기](https://sallyhadev.github.io/IT-DA/)

실제 화면과 개념도로 보는 전체 가이드. (저장소 안의 [`docs/index.html`](docs/index.html)을
GitHub Pages로 그대로 띄운 것이다)

## 다운로드

[Releases](../../releases/latest)에서 최신 zip을 받아 압축을 풀고 `itda.exe`를 실행한다.
Python 설치가 필요 없다.

### OCR(글자 읽기) — Tesseract 별도 설치

`글자 읽기(OCR)` 액션을 쓰려면 [Tesseract OCR (UB-Mannheim 빌드)](https://github.com/UB-Mannheim/tesseract/wiki)를
따로 설치해야 한다. [Windows 64bit 설치 파일 바로 받기](https://digi.bib.uni-mannheim.de/tesseract/tesseract-ocr-w64-setup-5.3.3.20231005.exe)

- 설치 중 **"Additional language data" 항목에서 반드시 `Korean`을 체크**할 것 — 기본값에는
  한국어가 빠져 있어 체크하지 않으면 한글 인식이 안 된다.
- 기본 경로(`C:\Program Files\Tesseract-OCR`)에 설치하면 잇다가 자동으로 찾는다. 다른 경로에
  설치했다면 환경변수 `ITDA_TESSERACT`에 `tesseract.exe`의 전체 경로를 지정한다.
- 설치돼 있지 않으면 OCR 액션 실행 시 로그에 설치 안내가 남을 뿐, 나머지 기능은 정상 동작한다.

## 특징

- **플로우차트로 짠다** — 시작·동작·분기·다중 분기·반복·플로우 호출 등 노드를 이어 순서를 만들고,
  노드 안에는 클릭·이미지 찾기 같은 액션을 순서대로 쌓는다.
- **상황을 인식한다** — 화면마다 판정 조건(이미지·창 제목·픽셀·OCR)을 등록해두면 엔진이
  지금이 어떤 상황인지 스스로 판정하고, 필요한 상황까지 최단 경로로 알아서 이동한다.
  광고 팝업 같은 "끼어드는 화면"도 자동으로 걷어내고 원래 하던 일로 복귀한다.
- **여러 플로우를 동시에 돌린다** — 플로우마다 독립된 스레드와 엔진에서 실행되고,
  변수·상황 판정도 서로 분리된다. 마우스·키보드처럼 실제로 하나뿐인 입력 장치만
  우선순위 기반으로 순서를 나눠 쓴다.
- **실행 전에 미리 본다** — `F5` 데모 재생은 실제 입력 없이 흐름과 로그·변수 변화만
  시뮬레이션한다. `F8` 검사는 끊긴 연결이나 순환 호출 같은 문제를 미리 잡아낸다.
- **사람처럼 움직인다** — 곡선 궤적, 가속/감속, 좌표·타이밍 오차를 프로파일로 켜고 끌 수 있다.

## 처음 매크로 만들기

1. **플로우를 만든다** — 팔레트에서 노드를 끌어다 놓고 연결한다.
   첫 노드는 보통 `창 맞추기`(대상 창을 정해진 크기로 고정 → 좌표가 어긋나지 않는다).
2. **타겟을 객체로 저장한다** — `F3` 스크린샷 도구로 하나씩, 또는 `F4` 객체화 도구로
   화면을 아이콘·글자·버튼 단위로 자동 분할해 한꺼번에.
3. **`F8` 검사** — 없는 객체·플로우 참조, 순환 호출 같은 문제를 미리 잡는다.
4. **`F5` 데모 재생** — 실제 입력 없이 흐름과 계획(좌표·궤적·소요시간)을 로그로 확인한다.
5. **`F9` 실제 실행** — 진짜 마우스·키보드로 동작한다. 여러 플로우를 한 번에 돌리려면 `F10`.

> **멈추는 방법: `F12`.** 잇다 창이 뒤에 있어도 동작하는 전역 단축키다.
> 매크로가 마우스를 잡고 있으면 정지 버튼을 누르기 어려우므로 이쪽을 기억해 두는 편이 좋다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 가운데 | 플로우차트 캔버스 (탭으로 여러 플로우 동시 편집) |
| 왼쪽 | 프로젝트(플로우 목록) / 팔레트(노드·액션) / 객체 저장소 |
| 오른쪽 | 노드 액션 목록 / 속성(스키마 자동 생성 폼) |
| 아래 | 로그 / 실행 상태(현재 상황 배지 + 변수 워치) |

단축키: `F2` 좌표 도구 · `F3` 스크린샷 도구 · `F4` 객체화 도구 · `F5` 데모 재생 ·
`F6` 상황 관리 · `F7` 타이밍 프로파일 · `F8` 검사 · `F9` 실제 실행 · `F10` 멀티 플로우 실행 ·
`F11` 상황 감시 · `F12` 실행 정지 · `Ctrl+L` 자동 정렬 · `Ctrl+0` 전체 보기

자세한 화면별 안내는 **[사용 설명서](https://sallyhadev.github.io/IT-DA/)** 참고.
